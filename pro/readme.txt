Premium add-on for Clandevs Smart Catalog Filters. Requires the free plugin.

== Description ==

Clandevs Smart Catalog Filters Pro extends the free plugin with powerful premium features.

= Pro Features =

* **Filter presets** — save and load filter combinations for quick access
* **Date range filter** — filter products by published or sale date
* **Advanced analytics** — date range filtering, CSV export, trend charts
* **Product comparison** — compare up to 4 products side-by-side
* **WooCommerce Blocks** — native block for the block editor
* **Drag-and-drop ordering** — reorder filter sections visually
* **Visual swatches** — assign images to attribute terms for visual filtering
* **Import/export settings** — backup and restore all plugin settings
* **Variation filtering** — filter by variation-level attributes
* **SEO-friendly URLs** — pretty permalinks for filtered pages
* **Multi-currency** — price filter support for multi-currency setups
* **Elementor widget** — drag-and-drop filter sidebar in Elementor

= Requirements =

* WordPress 6.0+
* WooCommerce 7.0+
* Clandevs Smart Catalog Filters (free version)

== Installation ==

1. Install and activate the free version first.
2. Upload the Pro plugin via Plugins > Add New > Upload Plugin.
3. Activate and enter your license key.
