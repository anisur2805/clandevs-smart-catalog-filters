Woo Filter Studio

Filter WooCommerce products by category, attributes, price, rating, stock, and more with AJAX and shortcode support (Elementor-friendly).

Requirements

  • WordPress 6.0+
  • WooCommerce 7.0+
  • PHP 7.4+

Installation

  • Upload the woo-filter-studio folder to /wp-content/plugins/.
  • Activate the plugin from the WordPress Plugins screen.
  • Ensure WooCommerce is installed and active.

Basic Usage

  • Shop archive pages automatically show the filter sidebar and layout enhancements.
  • Use the shortcode on any page to render filters and products:

[woo_filters]

Shortcode Options

  • per_page (default: 12) - number of products to show.
  • columns (default: 4) - number of product columns.
  • category (optional) - restrict to a product category slug.
  • show_filters (default: yes) - show or hide the filter sidebar.
  • show_pagination (default: yes) - show or hide pagination under results.

Filter Visibility Settings

Go to Woo Filter Studio > Woo Filter Studio Settings to enable or disable individual filter blocks (categories, brands, price, rating, availability, colors).

Styling Settings

Go to Woo Filter Studio > Woo Filter Studio Styling to select a preset skin and fine-tune colors, typography, spacing, and custom CSS.

Analytics

Go to Woo Filter Studio > Woo Filter Studio Analytics to see filter usage counts and reset analytics data when needed.

Uninstall Behavior

You can choose to delete plugin data on uninstall in Woo Filter Studio Settings under the Data Management section.
