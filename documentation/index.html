Advanced Product Filter

Filter WooCommerce products by category, price, and availability for free. Upgrade to Pro for brand, color, rating, analytics, and full styling.

Requirements

  • WordPress 6.0+
  • WooCommerce 7.0+
  • PHP 7.4+

Installation

  • Upload the advanced-product-filter folder to /wp-content/plugins/, or install from the WordPress plugin repository.
  • Activate the plugin from the WordPress Plugins screen.
  • Ensure WooCommerce is installed and active.
  • Go to Advanced Product Filter > Settings to configure which filters appear.
  • Visit your shop page — filters appear automatically.

Activate Pro License

  1. Purchase a Pro license from advanced-product-filter.clandevs.com.
  2. In WordPress admin, go to Advanced Product Filter > Account.
  3. Enter your license key and click Activate.
  4. Pro features unlock immediately. Your existing settings are preserved.

Start a Free Trial

  1. Go to Advanced Product Filter in your WordPress admin.
  2. Click Start a 14-day Free Trial — no credit card required.
  3. All Pro features are available for 14 days.
  4. When the trial ends, the plugin reverts to the free version with your settings intact.

Free vs Pro Features

Free: Category filter, price range slider, availability filters (in stock / on sale), AJAX filtering, shortcode support, mobile drawer, active filter chips, per-page switcher, Classic skin, 6 color controls.

Pro: Everything in Free plus brand filter, color swatch filter, rating filter, custom attribute filters, OR/AND logic toggle, Graphite & Sunrise skins, all 15 color controls, typography & layout, border radius controls, custom CSS, analytics dashboard.

Basic Usage

  • Shop archive pages automatically show the filter sidebar and layout enhancements.
  • Use the shortcode in a standard WordPress page or post content area to render filters and products:

[advanced_product_filter]

Shortcode Options

  • per_page (default: 12) - number of products to show.
  • columns (default: 4) - number of product columns.
  • category (optional) - restrict to a product category slug.
  • show_filters (default: yes) - show or hide the filter sidebar.
  • show_pagination (default: yes) - show or hide pagination under results.

Filter Visibility Settings

Go to Advanced Product Filter > Settings to enable or disable individual filter blocks. Free filters (categories, price, availability) can be toggled freely. Pro filters (brands, rating, colors) show a PRO badge and require an active license or trial.

Styling Settings

Go to Advanced Product Filter > Styling (the default admin page) to customize the filter appearance.

  • Free: Classic skin, 6 basic color controls (accent, sidebar background, sidebar border, heading, body text, muted text).
  • Pro: Graphite and Sunrise skins, all 15 color controls, typography & layout (font family, font size, sidebar width, gap), border radius controls, and custom CSS.

Analytics (Pro)

Go to Advanced Product Filter > Analytics to see filter usage counts, top used filters, and last event time. The analytics dashboard and tracking are available with an active Pro license or trial.

Uninstall Behavior

You can choose to delete plugin data on uninstall in Advanced Product Filter Settings under the Data Management section.
